# mapconstruction-fix

`version.dll` для **SA-MP Map Construction** (`editor.exe` от JernejL). Чинит редактор в памяти при запуске, сам `editor.exe` не меняется.

## Что исправляет

1. **«You cannot use the editor while game is running - close gta-sa, and try again.»**
   Редактор не ищет запущенную игру. Он пробует открыть `models\gta3.img` монопольно на запись и, если не вышло, показывает это сообщение и выходит. Сообщение появлялось и тогда, когда файл держал кто угодно другой (например, dev-сервер). Теперь эта проверка пропускается.
2. **Монопольное открытие файлов.** В таблице режимов общего доступа функции Delphi `SysUtils.FileOpen` режимы `fmShareCompat` и `fmShareExclusive` заменены на `FILE_SHARE_READ | FILE_SHARE_WRITE`. Файлы игры загружаются, даже если их держит запущенная GTA.
3. **Редактор в отдельной папке.** Если рядом с `editor.exe` нет `data\gta.dat`, папкой игры считается родительская. Свои файлы (кэш `gta_shapes\`, `PrefabPics\`) редактор строит от своей папки, а не от папки игры. Если положить редактор в корень игры, он работает как раньше.

4. **Видимые объекты-эффекты SA-MP** (огонь, дым, взрывы, вода, искры: `18668`–`18749` и другие, всего 81 модель в `SAMP.img`). Их DFF состоят из треугольника размером 1 мм и записи 2dEffect с именем частицы, поэтому в редакторе их не видно и не выделить. Когда редактор читает такую модель из `.img`, DLL отдаёт вместо неё ромб высотой 1,2 м с центром в точке эффекта. Цвет зависит от частицы:

   | Цвет | Частицы |
   |---|---|
   | оранжевый | огонь, пламя, вспышки (`fire*`, `flame*`, `molotov_flame`, `gunflash`, `jetthrust`…) |
   | красный | взрывы (`explosion_*`, `wallbust`) |
   | серый | дым, пыль, пар (`smoke*`, `exhale`, `teargas`, `vent`, `prt_sand`…) |
   | голубой | вода (`water_*`, `prt_*splash`, `prt_bubble`, `extinguisher`…) |
   | жёлтый | искры, осколки, нитро (`prt_spark*`, `prt_glass`, `nitro`, `overheat_car`…) |
   | малиновый | кровь, рвота (`prt_blood`, `blood_heli`, `puke`, `coke_*`) |
   | зелёный | всё остальное |

   Модель определяется по содержимому, а не по списку имён: в DFF должна быть частица 2dEffect, а вся геометрия меньше 5 мм. Файлы игры не меняются, в игре эффекты выглядят как обычно.

5. **Мир таким, каким его видит SA-MP.** SA-MP подменяет игре `main.scm` и `gta.dat` своими (из `samp.saa`), и мир в нём отличается от того, что редактор собирает из файлов игры:
   - IPL из архивов, которые не являются частью текстового IPL, игра грузит только по запросу скрипта (`REQUEST_IPL`). `main.scm` SA-MP запрашивает один из них — `crack` (наполнение цеха фабрики в Сан-Фиерро); `carter`, `truthsfarm`, `barriers1`, `barriers2` не запрашивает. Редактор догружал их все, теперь грузит только `crack`.
   - `SAMP\SAMP.ipl` (две постройки пляжного комплекса в LS) грузится: его добавляет `gta.dat` SA-MP.
   - 74 объекта, которые `main.scm` SA-MP ставит при запуске игры, грузятся как ещё один IPL: башенные и портовые краны со своими лодами, двери, вагончики на стройке в SF, ворота, лифты авианосца, прожекторы зоны 51 (повёрнуты на свои цели). DLL записывает этот IPL в `samp_scm.ipl` рядом с собой и загружает после IPL игры.
   - Сгоревший корпус фабрики в SF (`CF_ext_dem_SFS`) и его лод скрыты, как это делает `main.scm` SA-MP (`SET_VISIBILITY_OF_CLOSEST_OBJECT_OF_TYPE`). Скрытое здание не попадает в экспорт `RemoveBuildingForPlayer` и не возвращается командой очистки карты.

6. **Закрытие одного редактора закрывало все.** При закрытии окна редактор сохраняет закладки и виды, а потом завершает все процессы с именем `editor.exe` (обход списка процессов через Toolhelp), то есть и остальные открытые редакторы. Теперь он завершает только себя.

7. **«List index out of bounds (2)» в «Point camera at these Coords».** Если ввести только `x, y`, редактор успевал передвинуть камеру по X и Y, падал на третьем числе, и камера оставалась в сломанном состоянии: не наклонялась вверх-вниз, при полёте её перебрасывало. Теперь недостающая координата берётся из текущей точки, на которую смотрит камера: при `x, y` высота остаётся прежней.

8. **Вставка объекта с несуществующим ID.** Если по <kbd>Insert</kbd> ввести ID, которого нет ни в одном загруженном IDE (например, `111111`), редактор всё равно добавлял объект на карту. После этого каждая перерисовка падала с «Range check error», окно с ошибкой появлялось снова сразу после закрытия, и редактор приходилось завершать через диспетчер задач. Теперь такой ID не вставляется, редактор показывает предупреждение.

9. **Бэкап расставленных объектов.** Пока редактор работает, расставленные объекты и удалённые здания сохраняются в `backups\objects_<дата_время запуска>_<PID>.pwn` рядом с `editor.exe`. Формат тот же, что у экспорта редактора: `CreateObject(...)` (машины с ID 400–611 — `CreateVehicle(...)`) и `RemoveBuildingForPlayer(...)`. Строки `CreateObject` и `RemoveBuildingForPlayer` можно загрузить обратно импортом редактора.
   - Файл обновляется каждые 2 секунды, если что-то изменилось, и ещё раз при закрытии редактора. Пока ничего не расставлено, файл не создаётся.
   - На каждый запуск свой файл: новый запуск не затирает бэкап упавшего, а редакторы, открытые одновременно, не пишут в один файл.
   - Файл сначала пишется в `.tmp` и потом заменяет старый, поэтому падение во время записи не портит предыдущий бэкап.
   - Карта читается в главном потоке редактора (таймер `SetTimer`), то есть никогда не в момент, когда редактор её меняет.

10. **Окно About.** Под текстом авторов редактора добавлены строки «Fixes and improvements (mapconstruction-fix): Romzes» и ссылки на [тему на форуме](https://pawn.wiki/index.php?showtopic=595) и [репозиторий](https://github.com/Romz24/mapconstruction-fix). Ссылки открываются в браузере по клику. Размер окна не меняется: строки встают в пустое место над кнопкой.

Перед патчем DLL сверяет байты во всех местах правки. Если это другая сборка редактора, она ничего не меняет и только пробрасывает вызовы системной `version.dll`.

Поддерживаемая сборка: `editor.exe`, 1 310 720 байт, MD5 `bdde354101733b90ff2c3499dab2ddbc`.

## Установка

```
GTA San Andreas\
├─ data\, models\, SAMP\, gta_sa.exe ...
└─ editor\
   ├─ editor.exe          (оригинал)
   ├─ version.dll         (этот проект)
   ├─ GTAINTERFACE.dll
   ├─ newton.dll
   └─ background.txd
```

Чтобы вернуть стандартное поведение, удалите `version.dll`.

## Сборка

Нужна Visual Studio 2019 или новее с компонентом «Разработка классических приложений на C++» (MSVC x86).

```bat
build.bat
```

Результат: `build\version.dll`. Собрать и сразу положить к редактору:

```bat
build.bat "E:\Games\GTA San Andreas\editor"
```

### Тест маркеров

```bat
test.bat "E:\Games\GTA San Andreas"
```

Собирает `build\test_markers.exe`. Тест загружает настоящую `GTAINTERFACE.dll`, открывает `SAMP.img`, `custom.img`, `gta3.img`, `gta_int.img` и прогоняет каждый DFF через перехват так же, как это делает редактор. Он проверяет, что модели-эффекты заменены маркером, а все остальные файлы вернулись байт в байт.

### Объекты скрипта SA-MP

`src/scm_objects_ipl.h` генерируется из проекта samp-web, который исполняет стартовые миссии `main.scm` SA-MP и ставит объекты так же, как игра (подъём `CREATE_OBJECT` по коллизии, повороты, связи с лодами):

```bat
cd samp-web && npx tsx tools/sampscm/ipl.mts scm_objects.ipl
python tools/gen_scm_ipl.py <путь к scm_objects.ipl>
```

### Модель маркера

`src/marker_dff.h` генерируется скриптом `python tools/gen_marker.py`: форма и размер задаются там. Двусторонний октаэдр в формате RenderWare 3.6 со структурой чанков как у эффектов SA-MP. Тени граней запечены в цвета вершин, чтобы ромб выглядел объёмным и без освещения. Модель должна помещаться в 2048 байт: эффекты занимают в `.img` один сектор, и редактор выделяет буфер именно такого размера.

## Как это устроено

`editor.exe` импортирует системную `version.dll`. Windows сначала ищет DLL в папке программы, поэтому загружает эту, ещё до старта редактора. В `DllMain` она правит код и данные `editor.exe` (база `0x400000`, без ASLR).

| Адрес | Что |
|---|---|
| `0x4E4380` | `jne` на сообщение «close gta-sa» → переход дальше, к загрузке |
| `0x4FD14C` | `ShareMode[0..1]` в `SysUtils.FileOpen`: `0` → `3` |
| `0x4E562E` | `GameDir := ExtractFileDir(ExeName)` → `jmp` на заглушку: запоминает папку редактора, при отсутствии `data\gta.dat` берёт родительскую |
| 17 адресов | чтения `GameDir` при построении путей `gta_shapes\` и `PrefabPics\` → переменная «папка редактора» внутри DLL |
| `0x58E994` | ячейка импорта `GTAINTERFACE.IMGExportBuffer` → перехват, который после чтения модели заменяет эффекты маркером |
| `0x4E4882` | `jne` в цикле догрузки оставшихся IPL из архивов → `jmp` на заглушку: догружается только то, что запрашивает `main.scm` SA-MP (`crack.ipl`) |
| `0x4E494D` | `mov edx,'Processing LOD hierarchy'` → `jmp` на заглушку: `TMap.LoadIPL` (`0x4FA8AC`) для `SAMP.ipl` и `samp_scm.ipl`, затем скрытие по таблице `main.scm` (у записи здания байт `+0x3B`: 1 — удалено и экспортируется, наше 2 — только скрыто) |
| `0x4E7E22` | `TForm1.FormClose`: `OpenProcess`/`TerminateProcess` по неинициализированному PID и `KillTask(ExtractFileName(ExeName))` (`0x4DCF10`) → вызов DLL: последний бэкап объектов, затем `TerminateProcess(GetCurrentProcess(), 0)` |
| 6 вызовов `0x4E9982`…`0x4E99EC` | `GetFloat` (`0x4999D4`, проверяет `Count >= i` вместо `Count > i`) в `btn_camerahereClick` → заглушка: число из строки, если оно есть, иначе текущая координата точки обзора (`0x578F04`) |
| `0x4EAA78` | `call TForm1.insertobject` в обработчике <kbd>Insert</kbd> → заглушка: вставка, только если ID в пределах `0..19999` и в таблице определений `0x57A5B8` он не `nil`, иначе предупреждение |
| импорт `LoadResource`, `LockResource`, `SizeofResource` | для ресурса `RCDATA TWND_ABOUT` (DFM формы About, запись `0x5A1CA0`) отдают копию DFM в DLL с четырьмя дополнительными `TLabel`. Сам ресурс не трогается: Windows не находит ресурс, данные которого лежат вне образа |
| `0x4D9594` | `vmtMethodTable` формы `Twnd_about` → копия таблицы с `btn_clearClick` и двумя методами DLL для ссылок (`aboutForumClick`, `aboutRepoClick`) |

Все 17 функций системной `version.dll` пробрасываются с теми же номерами (заглушки находят адрес при первом вызове, `VerLanguageName*` переадресованы в `KERNEL32`). Это важно: драйвер видеокарты тоже использует `version.dll`. Если какой-то функции не хватает, драйвер не загружается, OpenGL откатывается на `GDI Generic`, и редактор пишет «Please install proper drivers for your graphics card».

## Ограничение

Если редактор что-то записывает в `.img`, пока игра запущена, игра может прочитать файл в промежуточном состоянии. Именно от этого защищала исходная проверка.
